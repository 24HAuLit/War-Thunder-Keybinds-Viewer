# Offline inherited-preset snapshot

`mod.rs` resolves the exact allowlisted presets recursively, base-first, using
`include_str!` snapshots and the existing text BLK parser. `import()` applies
export hotkey replacements and scalar axis overlays; `import_explicit()` skips
inheritance. No Rust dependency or application network access is needed.

Merge rules are evidenced by the pinned game's
[`controlspreset.nut`](https://github.com/gszabi99/War-Thunder-Datamine/blob/aa326f10c6ba7d523647572368ead2e4d51ffb4d/gui.vromfs.bin_u/scripts/controls/controlspreset.nut#L574-L620).
Only direct `default:t` references in version-5 controls are applied. Unknown
paths, unsupported versions, and includes remain visible warnings; arbitrary
filesystem/network paths are never opened.

## Complete default dependency chain

The arrows are the original `controls.basePresetPaths.default` values. Each
referenced path begins with `config/hotkeys/`; those values are left unchanged
in the generated files.

```text
hotkey.keyboard_ver1.blk
  -> hotkey.base.keyboard_simulator.blk
    -> hotkey.base.keyboard.blk
      -> hotkey.empty_ver1.blk
        -> hotkey.event.human.blk
          -> no default base
```

Despite its name, `empty_ver1` is not terminal. `event.human` contains version 5
and empty `hotkeys` and `axes` objects, with no `basePresetPaths` object. Empty
objects must remain blocks: absence and an explicit empty override are not
interchangeable. This generator neither merges presets nor interprets overrides.

## Reproduction and verification

Python **3.9+**, standard library only; run from the repository root (the script
also locates its data correctly when invoked from another working directory):

```sh
# Rebuild BLK files and manifest from the bundled JSON; no network.
python3 scripts/generate_presets.py

# Verify all raw source hashes, dependency closure, generated bytes, and manifest.
# No network and no writes.
python3 scripts/generate_presets.py --check

# Converter regression tests; no network and no writes.
python3 scripts/generate_presets.py --self-test

# Optional: refetch exactly the five pinned JSON sources, verify their hashes,
# then regenerate. Requires HTTPS access to raw.githubusercontent.com.
python3 scripts/generate_presets.py --fetch
```

The script never resolves a moving branch during normal reproduction. `--fetch`
follows only the default dependency closure of the four roots and refuses names
outside its five-file checksum allowlist. All sources and generated content are
validated before any output is written. Hash mismatches, missing sources, cycles,
or unexpected dependencies fail rather than silently producing partial data.
There are no generation timestamps, locale-dependent values, platform-dependent
newlines, or third-party Python packages. Outputs are UTF-8 with LF line endings.

To update the snapshot deliberately, resolve a new SHA with the API, inspect the
four roots and their recursive defaults, review rights/provenance again, update
the script's revision/version/checksum allowlist and this document, then fetch,
regenerate, test, and review the full data diff. There is intentionally no
unpinned update/crawl mode.

## Conversion contract and limitations

- The **entire document** is converted, including all `controls` sections
  (`version`, `basePresetPaths`, `hotkeys`, `axes`, `params` where present), not
  just keyboard bindings. No fields are filtered and no empty objects are removed.
- JSON object insertion order is preserved. Object arrays become repeated blocks
  with the same name, in array order. Scalar arrays become repeated properties,
  not bracketed values or comma-separated vectors.
- Booleans become `b=yes`/`b=no`, signed i32 integers `i`, finite floating-point
  values `r`, and strings `t`. A float such as `1.0` stays `r`, not `i`.
- Strings and quoted names use Dagor tilde escapes: `~~`, `~"`, `~n`, `~r`, `~t`.
  Unicode is retained as UTF-8. Tildes are escaped before other replacements.
- Unsupported/null values, empty or nested arrays, out-of-range integers,
  non-finite floats, duplicate JSON keys, and unsupported control characters
  fail explicitly. None occurs in the pinned inputs. JSON cannot restore any
  ordering/type information already lost by upstream's BLK-to-JSON extraction;
  this is a semantic conversion, not recovery of the original game BLK bytes.
- The existing parser additionally recognizes backslash escapes. The pinned
  inputs use slash-separated paths and contain no backslashes; arbitrary future
  backslash-bearing strings need a fresh parser-compatibility review, rather than
  treating this as a universal BLK converter.
- A newer/older game, device-specific preset, event, or local export may differ.
  Do not claim that this snapshot exhaustively describes current in-game controls
  or proves an unlisted key is free. Resolution selects known presets
  explicitly and keeps unknown references/version mismatches visible.
